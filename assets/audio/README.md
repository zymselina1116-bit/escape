# Audio Assets

This directory should contain the ambient audio loops for each scene.

## Required Files:

- `main.mp3` - Soft ticking and ambient wind for the Main Room
- `pool.mp3` - Echo, soft dripping, underwater resonance for the Pool Tunnel
- `hallway.mp3` - Echo, reverb hum, slow footsteps for the Hallway
- `garden.mp3` - Soft breeze, leaves rustling, faint birdsong for the Garden

## Notes:

All audio should be:
- Loopable (seamless loops)
- Low volume (0.3-0.5 range)
- Ambient/atmospheric in nature
- MP3 format for web compatibility

The application will automatically cross-fade between tracks when transitioning between scenes.
